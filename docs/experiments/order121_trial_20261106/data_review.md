# 【路线图第3步】落子次序专项数据独立复查

## 判断

数据合法性与采集流程可以通过，预先声明的数据门槛失败：训练后排优8/前排优16，共24；开发后排优1/前排优8，共9。开发后排方向不足预声明至少2例，因此应停止本轮训练，不补根、不放宽阈值。

几何筛选只保证“存在后排推进与前排连跳两种合法选择”，不会保证教师认为两种选择同样经常占优。front本来就按最大前进量、最多跳数选取，rear优先减少最远棋子距离；这是两类动作属性，不是两类真值标签。

## 标签0分解

15/48根被屏蔽，以下为互斥原因：先检查depth4/5任一同分，再检查方向翻转，最后检查稳定同号但depth5绝对分差不足2。

|原因|训练|开发|合计|
|---|---:|---:|---:|
|depth4同分，depth5非同分|2|1|3|
|depth5同分，depth4非同分|0|1|1|
|两深度分差方向翻转|1|3|4|
|两深度同号但depth5绝对分差仅1|5|2|7|
|合计|8|7|15|

没有双深度同时同分根。这些屏蔽按原门槛执行，不能为了类别数量把小分差或翻转标签补回。

全部48根、15个屏蔽根、原始分数与几何特征保留于data_review.json及原collection，失败门槛不掩盖。本轮不能当成已具备双方向开发数据的训练集。若将来重新设计，应在新预声明和全新根上检验几何桶是否覆盖足够多任务情境；当前开发标签已经看过，不能据这些标签改桶后称同一开发仍独立。

## 后排模板与“小步接入跳链”的距离

原rear规则只要求最远棋子距离减少，既没有限制必须邻步，也没有要求落点接入下一条连跳。以下只做几何核对：在rear child上调用同一棋子的legal_paths，检查是否有返回路径至少2跳且继续前进。不走对手、不搜索，称为“静态接力潜力”，不保证下一轮仍可走。

|划分/标签|根数|rear多跳|rear邻步|静态前进连跳潜力|邻步＋静态连跳|rear段数分布|
|---|---:|---:|---:|---:|---:|---|
|train/all|32|7|21|4|4|{1: 25, 3: 3, 2: 1, 5: 3}|
|train/-1|16|2|13|0|0|{1: 14, 2: 1, 5: 1}|
|train/0|8|3|3|1|1|{1: 5, 3: 2, 5: 1}|
|train/1|8|2|5|3|3|{1: 6, 5: 1, 3: 1}|
|development/all|16|2|12|4|4|{3: 1, 1: 14, 2: 1}|
|development/-1|8|2|6|3|3|{3: 1, 1: 6, 2: 1}|
|development/0|7|0|5|1|1|{1: 7}|
|development/1|1|0|1|0|0|{1: 1}|
|all/all|48|9|33|8|8|{1: 39, 3: 4, 2: 2, 5: 3}|

标签+1为稳定后排优、−1为稳定前排优、0为按原深度门槛屏蔽。段数len(path)−1不同于空间位移：一段可为邻步或一次跳跃，必须另看邻步列。

当前数据只能称“减少最远距离的后排动作 vs 前排前进连跳”专项，不能直接称“小步接力”专项。未检查静态接力是模板覆盖缺口；类别不足不能简单归因随机抽样。本表用于定位模板与研究目标的距离，不据当前标签改阈值补样本。完整每例rear与静态接力示例保存在JSON。
