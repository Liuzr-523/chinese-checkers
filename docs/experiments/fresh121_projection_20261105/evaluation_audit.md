# 独立评测复核：新开局上的回放投影对照

本复核只读取本轮已冻结的结果与64例实际选择；没有再次调用模型、教师或对局，也没有根据结果改门槛。

## 判断

投影组没有达到预声明开发门槛，不晋升、不进入独立整局确认。普通广开局训练相对v3在本开发集有小幅静态指标改善；新增投影没有在差棋数与平均分差上进一步改善。这个结论不能简写成“所有NN训练都无改善”。

|模型|差棋数（分差至少4）|专家同分数|平均分差|
|---|---:|---:|---:|
|v3|29/64|21/64|4.984375|
|普通广开局训练|27/64|23/64|4.671875|
|增加回放冲突投影|27/64|25/64|4.671875|

两训练组相对v3少2个差棋，平均分差减少0.3125；这是固定深度专家质量开发指标，不是整局胜率。64例只有32个随机开局分支，不能当64个独立比赛样本。

## 投影具体改变了什么

投影与控制有61/64例起终点完全相同。其余3例：

|分支|走棋方|己方步数|控制分差|投影分差|变化|
|---|---:|---:|---:|---:|---|
|3|P1|10|9|14|恶化5分，仍为差棋|
|22|P2|9|2|0|改善2分，达到专家同分|
|31|P2|10|3|0|改善3分，达到专家同分|

两次改善共5分，被一次恶化5分抵消；没有任何例的“分差至少4”分类改变。因此同分数增加2，而差棋数和平均分差均未改变，并非两模型完全相同。

每分支含双方各一根，下表比较分支两根分差之和；改善指分差减少。

|比较|改善分支|恶化分支|相同分支|

## 门槛复算

- 新差棋至少比控制少4：失败（27对27）。
- 新差棋不多于v3：通过（27对29）。
- 新平均分差不高于控制与v3：通过（4.671875等于控制，小于v3）。
- 旧策略CE不超v3+0.05：通过。
- 旧价值MSE不超v3+0.05：失败。精确上限1.0595422140124382，投影组1.0599820807370803，超出0.0004398667246422；不因接近门槛而放宽。
- 普通留出CE不超v3+0.05：通过。
