# 25%／50%／75%开局样本份额实验

**决定：三组均未达到资格，不进入整局验收，不更新冠军。GUI继续使用v3＋可关闭的开局库。**

## 实验设计

相同v3/CNN/AdamW/lr3e-5，各2400次更新，每批16，总暴露38400次。开局样本分别4/8/12个，普通样本分别12/8/4个；策略损失按实际份额加权。真实value、KL .1、value函数保留 .1保持定义一致。原始NN关闭外部开局库。

565个训练局面、128个留出局面，镜像同组，前3步用于训练回归。三个方案从同一随机母序列取前缀，保存哈希和暴露计数。固定最终检查点，不按曲线最优点选模型。

资格预先定义：训练命中>=90%，留出比v3至少提高10个百分点，标准双方前三步6个局面全命中，旧策略CE与旧value MSE各不高于v3+.05，普通新策略CE不高于v3+.05。达标后双方开相同开局库，固定120+40+40局验收。

## 结果

|方案|训练库招命中|留出库招命中|标准前三步6局面命中|旧策略CE|旧value MSE|
|---|---:|---:|---:|---:|---:|
|v3|40.7%|37.5%|83.3%|2.117|1.010|
|book25|45.3%|38.3%|66.7%|2.088|1.060|
|book50|50.3%|39.8%|100.0%|2.121|1.060|
|book75|51.7%|40.6%|100.0%|2.194|1.071|

## 分阶段定位

|方案|训练第1—3步（73例）|训练第4—6步（144例）|训练第7—10步（348例）|留出第4—6步（24例）|留出第7—10步（104例）|
|---|---:|---:|---:|---:|---:|
|v3|56.2%|41.7%|37.1%|29.2%|39.4%|
|book25|69.9%|50.0%|38.2%|33.3%|39.4%|
|book50|89.0%|58.3%|38.8%|41.7%|39.4%|
|book75|89.0%|58.3%|41.1%|45.8%|39.4%|

前三步全部进入训练回归，没有相应留出数据。标准6局面全部命中指首选属于该局面的库推荐集合，包含多种允许招法。

提高份额主要帮助了前3步；50%组在标准6局面全部命中，前3步的所有训练分支达到89.0%。后7步仍明显欠拟合：第7—10步留出命中三组均39.4%，训练最高41.1%。75%继续增加开局份额，旧策略CE升到2.194，旧能力损失明显。

## 难例复核

50%组第7—10步相对v3新学对18例、把原来正确的12例学错，净增加6例；201例在训练前后均未选到库招。75%组对应新学对27例、新学错13例、192例前后均错。错误主要集中在后段大量样本尚未拟合，不能靠只看总体训练损失决定升级。具体高置信错误路径保存在hard_cases.json。

局部可见性审查找出6个推荐相反、但两个动作所见局部输入相同的样本对；其中互不重叠的仅2对，真实v3对应动作logit逐值相同。这个小规模问题先记录，当前数百个错误仍需检查训练目标与共享表示，不直接据此换架构。

## 本轮修复的数据错误

原镜像增强在已存在原库记录的镜像局面上，沿用了另一侧的推荐集合。693例中12个训练例与实际查库不一致，留出128例没有变化。已改为逐局面调用运行时查库生成标签，新增693例一致性回归。旧份额实验停止并标为无效，数据/代码/过程保留，三个方案使用修正版同预算重跑；本报告只采用修正版结果。

## 下一步

50%方案保留作难例诊断起点，不登记为新模型。下一轮应选一小批第7—10步难例，先验证能否在保留旧能力时拟合，再检查其训练目标与策略读出；不继续提高开局份额，也不启动更大自对弈。现有外部开局库实战功能保留。
