# Clysto前10步开局树接入121格

本次完成开局树提取、GUI开关接入、原始NN模仿试验与带库完整对局测试。GUI默认开启，随时可关闭；冠军权重仍为v3。

## 库数据与使用

380个命中局面、514条推荐着法，覆盖双方各前10步；514条全部严格121合法。运行只需本仓库opening121_book.json，不依赖原版Clysto工程。所有分支按完整棋盘和走棋方匹配，支持左右镜像，重复终局或20手后自动交回引擎。
GUI设置页点击“Clysto开局库：开/关”；棋盘底部标明上一AI步来自库还是搜索。开关对Python参考、C-PVS和登记NN分别包装，核心引擎及评测默认仍保持无库。
初始几步在原库允许的候选中优先选择用户示范路线，其余分支保留原库推荐。

## 原始NN模仿结果

训练565个局面，留出128个，左右镜像同组；前6总手数纳入训练回归。两个模型从同v3开始，各1200更新，根样本4/普通样本12，普通样本顺序相同，原始网络不调用BookEngine。开局样本只监督策略，不赋胜负值。
|模型|训练库招命中|留出库招命中|留出库招总概率|旧策略交叉熵|
|---|---:|---:|---:|---:|
|v3|40.9%|37.5%|24.8%|2.117|
|prior_decisions|44.4%|37.5%|23.2%|2.091|
|opening_book|43.9%|39.1%|24.1%|2.098|

开局模仿候选留出命中只增加2个局面，未登记。实际开局功能提升来自独立开局库，不包装为神经网络棋力提升。

## 带库与无库完整对局

双方均为原v3/MCTS32，唯一差异是是否启用开局库。
|起始条件|带库方胜|负|和|
|---|---:|---:|---:|
|标准初始局面，双方交换|2|0|0|
|20个库内分支，双方交换|24|14|2|

共42局全部合法重放、真实终局核对通过，39条不同的后续走法序列。标准初始局面单独报告，不把重复同一确定开局当作额外独立样本。分支取自同一开局树，统计用于说明本机v3上的使用效果。

## 复现

```sh
python -m unittest discover -s tests -q
python arena_opening121.py --out nn_checkpoints/experiments/your_opening_book_arena
python train_opening121.py --out nn_checkpoints/experiments/your_opening_imitation
```

GUI只需安装pygame；NN与实验另需本机v3权重、登记与历史回放数据。提取原库需设置CLYSTO_DIR，再运行export_opening121.py。上游book.hpp/constants.hpp哈希记录在opening121_book.json中。
本次不修改C内核，不修改冠军登记。完整配对棋谱、训练结果、数据配置和中文图表随报告保存。
