## 复算定义

先用dual121_data.load_pilot从原始冻结dataset建立train value/policy映射，按sample_id关联；late只取terminal_distance<=16。每次先从late按排序group均匀抽8条，再从全value按group均匀抽8条，再从policy按group均匀抽16条，组内有放回；RNG种子111071。另一个种子111072按旧池长度抽old8/normal8。对每步value/policy ID和old/normal索引的sort_keys JSON字节依次SHA256，与两组记录核对。

组曝光、累计唯一ID、每批重复ID与board:player均从重建实际序列重新计算，而非直接复制原汇总。全部关键输入SHA及配置输入逐一检查结果保存在sampling_audit_review.json。本审计不运行训练、模型评测或教师查询。
