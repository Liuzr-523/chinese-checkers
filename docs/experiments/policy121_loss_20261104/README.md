# 121格候选输棋分析：优先修中盘调度

本轮分析完成，模型保持v3。下一项修正应聚焦20—40手的中盘调度和推进连续性，先用完整续弈筛出有收益的决策，再做训练。

## 对局与结论

来源：固定候选原配方种子110401对v3的120局独立验收，61胜54负5和。同开局交换先后手；11组开局双方都输，共22盘。完整120棋谱收录confirmation.jsonl，逐手合法重放及终局核对通过。

“剩余距离”用棋子到未填目标格的最小邻接步数匹配计算，已入营棋子锁定。它用于观察几何推进，尚未考虑可用跳桥和当前占用。

|总手数|61盘胜局平均剩余距离缺口|54盘败局平均剩余距离缺口|
|---|---:|---:|
|20|−1.16|+2.07|
|40|−4.79|+5.72|
|60|−6.10|+8.87|
|80|−6.00|+8.75（52盘尚未结束）|

正数表示候选落后。败局在开局末已有小幅劣势，差距在中盘持续扩大。54盘败局中30盘进入了八子到家阶段，16盘最终停在九子到家；还有24盘连八子都没到。因此，不能只根据“最后一子没进营”就把失败归为收官问题。

## 固定深度专家复查

在双败开局中，每盘每阶段先选一个推进收益较差的代表动作，再按开局组去重，每阶段抽8个，共24个。阶段定义：自身>=7子入营为收官，其余总手数<24为开局，否则中盘。这是有针对性的抽查，不用来估计全局各阶段错误率。

老师为Clysto评估表派生121版本，使用本地strict121规则，不含原版81格开局库。根搜索固定完成深度5，强制动作子搜索深度4；专家最佳根/子分数全部一致。

|阶段|复查动作|与专家差至少4分|
|---|---:|---:|
|开局|8|5|
|中盘|8|5|
|收官|8|0|

## 双分支真实续弈

选4处评分分歧明显、开局组不同的局面。分别强制原走法/专家走法，然后两边都由固定深度4专家走到真实终局，共8条棋谱。两分支后续控制策略相同，观察第一手变化的影响；这里的结果是专家续弈结果，不是原NN对局的重赛胜率。

|开局组/候选方/总手数|阶段|原走法|专家改走|原分支|改走分支|
|---|---|---|---|---|---|
|2 / P2 / 17|开局|111→103|113→104|胜，120手结束|胜，124手结束|
|36 / P2 / 19|开局|111→103|112→103|胜，110手结束|负，99手结束|
|15 / P1 / 30|中盘|9→8|70→69|负，136手结束|和，117手结束|
|13 / P1 / 46|中盘|42→41|61→71|胜，93手结束|胜，95手结束|

值得保留的中盘例子是第15组、第30手：候选还没有棋子入营，目标匹配距离77，对手71，已经落后6。原招移动后距离仍77；改走70→69后，续弈从失败变为同轮到家和棋。专家首步70→69腾出了中段落点70；候选下一次走棋随即执行29→52→70的连跳。原分支在该回合没有这条落点可用，转而执行61→80→105→116。这给出了一个具体的调度训练方向：学习何时腾出落点，为后续棋子保留连跳线路。完整首步与双方后续路径见branches.json，可以重放检查。

另一个关键发现：第36组的专家招法静态分高10分，实际续弈却由胜变负。后续数据不能只按固定深度评分差生成强标签，必须保留分支续弈验证。4处中有3处原走法在专家接管后也能取胜，原NN的后续决策同样值得排查。

## 下一次修正建议

1. 样本重点从20—40手中盘取，不再先堆收官样本。
2. 收集中盘候选与专家分歧，统一后续控制策略进行双分支续弈，优先保留能改善真实结果的首步。当前只有1个正向例子，先收集一小批，不直接拿单例大训。
3. 将有效首步独立成池，明确分配训练份额，保留普通回放；以新开局组检查是否改善实际调度与旧能力，再进入整局验收。
4. 若静态评分与分支结果持续相反，优先修教师筛选/搜索预算，不把矛盾标签继续灌给CNN。

## 复现

基础统计只依赖Python标准库：

```sh
python3 diagnostics/analyze121_losses.py --games docs/experiments/policy121_loss_20261104/confirmation.jsonl --out /tmp/policy121_loss_repro
python3 -m unittest discover -s tests -p test_loss121_analysis.py
```

可选专家续弈需要C编译器和当前Python开发头文件。冻结C源码与表已随提交提供，不需要神经网络权重或原版Clysto工程：

```sh
python3 diagnostics/build121_analysis_expert.py
python3 diagnostics/probe121_loss_branches.py --folder /tmp/policy121_loss_repro
```

图表额外需要matplotlib与中文字体：

```sh
python3 diagnostics/plot121_loss_analysis.py docs/experiments/policy121_loss_20261104
```

根/续弈固定深度会拒绝未完成搜索。输入棋谱、源代码及老师来源哈希见input_sha256.txt与provenance.json；PNG/SVG为简体中文分析图。模型参数与临时实验目录留在本机。
