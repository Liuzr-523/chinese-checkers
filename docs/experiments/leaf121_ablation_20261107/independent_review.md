# 叶子估值对照：独立设计审查

路线图第3步；固定现役v3 CNN与strict121，不训练、不晋升。48根与前6根实战均已用于诊断，不能称全新独立验收。

## 对照能回答的问题

同一CNN策略prior、PUCT系数、FPU、温度和规则下，替换非终局叶值为NN、0、Clysto静态`tanh(eval/40)`，可观察叶值来源如何影响访问分配与实际选招。真实终局±1优先于三类叶值；zero不能将真实胜负也置零。静态Clysto不是完整搜索教师，也不是独立证明的真实价值。

32/128/512用于固定模拟量对照，不能解释成相同时间或相同深度。软100ms实战用于现实时间条件诊断，应报告实际模拟数、墙钟/CPU时间、超限次数及最大超限。CNN每次仍计算策略和value，即使value被zero或handcrafted覆盖；对照不等于为handcrafted优化后的最快实现。

pure_policy只一次forward与合法动作argmax，不给它伪造100ms，也不在它未用完预算时等待凑时长。应单列耗时与资源，不能称四臂严格等算力。

## 实现审查要点

- 三搜索臂保持`noise=False, root_safety=False, heuristic_mix=0, fpu_mode=zero, policy_temperature=1`，不更换策略或模型参数。
- handcrafted只替换非终局叶值，正负视角为该叶当前走棋方；统一后与NN值走同一回传反号。不能同时把`value_scale=0`施加于handcrafted。
- 根与所有simulation保留完整重复历史及ply；纯策略也从同一个完整opening重放。
- 对手统一Clysto派生、100ms、同max_depth；每个根交换NN方身份，而strict规则P1仍先手。
- 每臂12局只是6根配对诊断，不以48条相关游戏当48个完全独立开局；按根、NN阵营报告结果。
- 11个pair稳定偏好仅描述原depth3/4固定续弈条件；候选外未知，不能强制归零/记错。新实战胜负与pair标签是不同证据。
- 本次不选“最佳臂”部署；如果需要后续正式验收，须另固定候选和全新隔离开局。

独立审计只重放归档与重算摘要，不重复MCTS或实战，不据结果补局、改预算或调tanh尺度。
