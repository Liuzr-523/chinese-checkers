# 第一步：策略概率、实际首选与数据分布的迁移诊断

## 范围

这是对既有v3、control、projected固定检查点的事后只读forward。没有训练、教师查询、新对局、模型选择或门槛修改。既有64根已经是开发历史，本次不是再次独立验收。三模型全部192个新开发首选均与原冻结评测记录一致；原实际动作专家分数直接复用，不对其他动作补评分。

代码`diagnostics/diagnose121_transfer.py`；机器记录`transfer.json`保存逐例、双方、己方第1—10步分层、比较轨迹、几何分布与输入/模型/源码哈希。

训练565及旧留出128的目标是原开局库推荐集合；64根目标是depth5教师的**单一建议动作**。这里统计单建议概率/名次，不冒称完整最佳动作集合。其他动作也可能专家同分，因此本报告单建议命中13/18/20与原完整质量记录的专家同分21/23/25不是同一指标。旧128存在已知19个转方等价跨组轨道，仅作诊断。

## 结论

训练确实把概率与名次往教师方向推了；许多增量没有改变网络首选。投影的额外变化尤其小：新64根中43例单建议概率上升，40例首选未变，最终只改变3个首选。另一个直接可测的问题是**开局库局面与随机开发根的棋子进度差别很大**，同时目标教师定义不同。接下来应优先明确教师目标并检查滞后开局覆盖，不能把新开发的弱结果只归为CNN容量或梯度失效。

## 概率、名次与间隔

## 输入分布差别

将双方都归一到向前为纵坐标增大的视角，初始己方棋子位于负纵坐标；均值越大表示总体越前进。“出营”仅指当前不在本方初始10格的棋子数，不等于历史上从未回营。

|局面池|例数|平均已出营棋子|己方棋子平均前向纵坐标|
|---|---:|---:|---:|
|全部开局库训练|565|5.24|-4.05|
|同为第7—10步的开局库训练|348|6.64|-3.37|
|同为第7—10步的旧留出|104|6.73|-3.32|
|随机新开发第7—10步|64|3.17|-5.31|

即便匹配第7—10步，随机根平均少出营约3.47子，整体落后约1.93行。新64根的棋子全在归一纵坐标-8到-2；库训练后段已有不少棋子抵达-1、0乃至更前。完整17行直方图在JSON。相同步数并不代表相同棋形：库里是专家开局结构，随机合法走法容易在营内往返。

这个差异为覆盖不足提供了具体证据，但本次同时换了输入分布和目标教师，不能把全部性能落差单独归因于某一个因素。

## 下一步用途

先把训练目标分清：学习原库推荐，还是学习固定深度专家对随机滞后局面的修正。随后按双方、进度和阶段核查普通回放已有覆盖，再决定是否用与64根完全隔离的新训练局面补充滞后开局。原64只能保留为已使用开发，不加入训练后又拿来验收。

目前证据支持“覆盖/目标转化需要改进”，不支持继续在64根上扫描投影强度，也不支持仅凭训练损失下降升级。所有模型和当前冠军保持原样。

验证：3项新增单元测试通过，覆盖集合概率与同分名次、稳定首选、转方几何一致、概率提高但首选不变。分析脚本事后forward对原冻结首选一致性断言全部通过。
