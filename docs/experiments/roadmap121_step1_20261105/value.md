## 结论及阵营分布核查

v3价值输出幅度很小，约四分之三留出样本|v|<0.1；它不是严格常量，但整体未优于常数0基线。control/projected输出幅度增大后，留出误差和负相关反而加重，饱和比例仍为0；问题不是tanh输出饱和。

normal的训练与留出阵营结果方向翻转：训练12局为P1胜7、P2胜3、真实等轮和2；留出4局为P1胜1、P2胜3。总体正负接近均衡会掩盖这种偏置。v3预测在两组始终P1偏正、P2偏负，符合训练阵营倾向，却与留出倾向相反。总体训练相关不能直接视为局面区分能力；分玩家后相关接近0。

优先核查并平衡普通数据的阵营/对局来源分布，按对局组及几何轨道保守隔离重建评估，再诊断价值监督如何提供局面信息。几何轨道隔离用于防止近似样本泄漏，不等于断言博弈对称。strict规则固定P1先手，等轮判和带有身份语义；身份平面应保留，转方后的输出差仅是身份敏感性证据，不据此判编码错误、删除身份或翻转标签。当前样本少且时序相关，不据此再做大训练。
