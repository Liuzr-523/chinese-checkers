# 121格迁移记录

2026-10-28，第一阶段完成：独立规则、GUI和参考搜索。81格规则、C内核、模型、数据均未改变。尚未完成 C-PVS 和神经网络迁移，尚无同规则 JumpStar 棋力排名。

## 使用

运行原 `gui.py`，设置页点击「121格 · 独立模式」。也可以直接运行 `gui121.py`。双方分别选择人类或121格参考搜索，支持慢速逐跳动画、路径淡入淡出、步数、悔棋、返回设置。参考搜索是新写的 Python alpha-beta 基线，不是 C-PVS，不是训练后的模型。严格规则下红方固定先手；可以更换双方身份，暂不提供改动规则的青方先手。

## 固定规则

采用 CCERL-2P10-v2 / CCZ-121-Strict-LG-v2：121格、每方10子、侧营开放、目标营锁定（包括跳链内部）、堵营判胜、同轮完成判和、三次同走棋方局面重复判和、240手上限判和。限步和棋是此模式明示的对局规则；今后若训练将其用于胜负标签，必须携带规则版本，不能混入81格未结束实验的伪胜负。

规则说明来源：第三方独立安装目录 `nn_checkpoints/third_party/jumpstar/docs/benchmark/CCERL-2P10-v2.md`。Python规则独立实现；未将第三方C++代码复制进项目。对拍需要另行编译第三方裁判；GUI与规则本身不依赖它。

### 实测结果

- C/Python：240局面走法集合、双方评估数值和位置终局0差异。
- 20个固定深度局面（4个深度3、16个深度2）：C PVS分数与独立Python alpha-beta完全一致；另对C所选走法求精确值，确认即使并列最优也确实最优。
- 覆盖进营锁定、同轮完成判和、堵营、第三次重复、子节点第三次重复、240手限步、非法输入、极短超时、并发搜索、GUI选中C并传递历史。
- 最后构建1秒吞吐：Python约1.63万节点/秒，C约59.5万节点/秒，约36.6倍；完成深度5→7。Python使用alpha-beta，C使用PVS，节点口径/访问顺序不同，该比值不能当作棋力比值。
- 同规则配对4局：每方0.1秒，2个固定6手随机开局分别交换引擎执棋方；C **4胜0负0和**，共109、106、103、100手，均为 `all_pieces_in_goal`。仅为小规模参考AI对战，不能据此推断JumpStar冠军或人类等级。
- 旧81格 `verify_ccore.py` 四步全部通过，最优走法0差异；未改原内核、评估或训练数据。
